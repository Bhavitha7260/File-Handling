# File-Handling
File Handling using python
File Handling Mini Project

Project Description

The File Handling Mini Project is a simple Python application that allows users to create, view, and clear notes using text files. It demonstrates how Python can store and retrieve information from files. The program uses a menu-driven interface so users can select the operation they want to perform.

Features

- Add Notes: Allows users to enter and save notes.
- View Notes: Reads and displays previously saved notes.
- Clear Notes: Removes all saved notes from the file.
- Permanent Storage: Saves notes in a text file named "notes.txt".
- Menu-Driven Interface: Provides simple options for managing notes.
- Error Handling: Handles cases where the notes file does not exist.

Technologies Used

- Python 3
- File handling ("open()", "read()", "write()")
- Functions
- Loops and conditional statements
- Exception handling

How to Run

1. Install Python on your computer.

2. Open the project folder in Visual Studio Code.

3. Save the program as "file_handling.py".

4. Open the VS Code terminal.

5. Run the following command:
   
   python file_handling.py

Learning Outcomes

- Understanding file operations in Python.
- Reading and writing text files.
- Using functions to organize code.

Conclusion

The File Handling Mini Project demonstrates how Python can be used to store, retrieve, and manage text data in files. It helps beginners understand file operations and basic error handling.
